# 付费意愿（WTP）访谈脚本 — 繁育者（中国）

*用于 Pet Health OS · 访谈对象为猫舍/犬舍 · 每次访谈约 30–45 分钟。*

这些访谈的目的**不是**推销，也**不是**凭空问"你愿意付 X 吗？"。而是要：(1) 确认问题真实存在且代价不小；(2) 挖掘真实的价格信号。**只有痛点真实，价格数字才有意义。**

---

## 使用前必读

**核心原则（源自《The Mom Test》）：**

- **聊他们的生活，而不是你的产品。** 问他们*现在*怎么做、*上一次*发生了什么——过去的行为能预测付费，对未来的看法不能。
- **不到最后不要介绍产品。** 你一旦提前描述产品，得到的会是客气话，而不是真相。
- **追问细节和数字。** "挺麻烦的"没有价值；"上个月我丢了 3 单、退款了 1.2 万元"才是金矿。
- **被夸奖是警示，不是胜利。** "好主意！"= 你什么都没学到。要找的是*实际承诺*（时间、金钱、声誉、转介绍）。
- **少说多听。** 自己说话尽量不超过 30%。沉默能逼出真话。

**执行要点：**

- **访谈对象：** 真正在*卖*动物的繁育者。猫舍（猫）和犬舍（狗）都要；规模大（多只种母/种公）和小（1–2 只）的都要。
- **数量：** 先做约 10–15 个再下结论；当答案开始重复时即可停止。
- **记录：** 先征得同意；否则逐字记笔记（记他们的原话，不要用你的转述）。
- **唯一铁律：** 永远不要先报价。让他们先说数字，你再复述并追问。

---

## 第 0 节 — 暖场与征得同意（2 分钟）

- 感谢您抽时间——我在研究繁育者如何管理动物健康和销售，**今天不卖任何东西**，只是来学习。方便我做点记录吗？
- 先聊聊您的猫舍/犬舍吧——您主要繁育什么？做多久了？

## 第 1 节 — 他们的经营情况（背景 + 决定价格上限的数字）（5 分钟）

> *原因：定价随他们的收入和规模而变。卖 3 万元一只小猫的繁育者，和业余爱好者的付费意愿天差地别。*

- 您目前有多少只种用动物？一年大概几窝？
- 一年大概卖出多少只动物？
- 您的动物单价通常在什么区间？
- 您从哪里找买家？（微信、朋友圈、抖音、闲鱼、线下、转介绍……）
- 这是您的全职生意，还是副业/爱好？

## 第 2 节 — 他们目前如何管理健康（行为 + 痛点）（8 分钟）

> *原因：这是"健康档案"要解决的事。找出他们现在的"凑合办法"以及它的漏洞。*

- 请带我走一遍：现在一只动物从出生到卖出，您是怎么记录它的健康状况的？（追问：本子？微信记录？Excel？全靠记忆？还是某个兽医系统？）
- 如果方便，能给我看看实际长什么样吗？*（请对方展示。）*
- 上一次有动物生病是什么时候？请详细讲讲当时发生了什么、您怎么处理的。
- 在做这些记录时，最烦人或最有风险的环节是什么？
- 您有没有丢失或忘记过某条健康信息、事后特别后悔的？当时怎么样了？
- 这么多只动物，您怎么追踪疫苗、驱虫和看诊的时间安排？

## 第 3 节 — 销售与交接（护照功能——你的切入点）（8 分钟）

> *原因：你的差异化就在这里。"星期猫/星期狗"的担忧是情感核心——让他们自己提；如果不提，再温和地问。*

- 您卖一只动物时，买家会问哪些关于健康/血统的问题？
- 您现在会给买家什么？（疫苗本？血统证书？口头承诺？一条微信消息？还是什么都没有？）
- 买家会不会担心带回家后动物会生病？您怎么打消他们的顾虑？*（留意"星期猫/星期狗"。）*
- 有没有买家回来说动物生病了——发生过纠纷、退款或差评吗？请讲讲最糟糕的那一次。
- 您的口碑在多大程度上取决于买家相信"您的动物是健康的"？
- 卖出之后，买家会不会回来问您健康/养护方面的问题？多久一次？

## 第 4 节 — 量化痛点（把痛点变成投资回报）（5 分钟）

> *原因：他们自己的数字，就是你后面用来对比价格的"价值锚点"。*

- 每周大概要花多少时间在健康记录和回答买家问题上？
- 过去一年，因为以下原因您估计损失了多少钱：动物生病、退货/退款、或因健康/信任问题而黄掉的订单？
- 如果有个工具能可靠地避免其中哪怕一类损失，这对您值多少钱？
- 经营猫舍/犬舍，您现在会为哪些东西*付费*？（兽医、软件、营销/投流、注册登记、美容……）每月大概多少？

## 第 5 节 — 概念反馈（现在可以介绍产品了——简短、中立）（4 分钟）

> *控制在两句话内。不要过度推销。观察他们的表情。*

- "现在有些繁育者开始用一种工具：你用大白话记录每只动物的健康状况，AI 会帮你尽早发现问题、并整理好给兽医看的资料；当你卖出时，这只动物的完整健康史会作为一份可分享的记录转交给买家，买家可以终身保存。" 您的第一反应是什么？（请讲真心话。）
- 其中哪一部分——如果有的话——是真正对*您*有用的？哪部分是可有可无的？
- 在您考虑使用之前，它必须先做到什么？

## 第 6 节 — 付费意愿（务必在以上环节之后再问）（8 分钟）

价格统一按**每月、每个猫舍/犬舍**来框定（也可顺便问年付）。让他们用自己的单位/数字回答；你复述他们的数字，并追问"为什么是这个数？"

### 6a. Van Westendorp 价格敏感度测试（四个问题，按此顺序问）

1. 每月多少钱会让您觉得**太贵了、根本不会考虑**？
2. 每月多少钱开始让您觉得**有点贵，但还值得考虑**？
3. 每月多少钱会让您觉得**很划算、物有所值**？
4. 每月多少钱会**便宜到让您怀疑它靠不靠谱**？

*（把许多次访谈的这四个数字汇总作图，就能看出可接受的价格区间。）*

### 6b. Gabor-Granger 测试（测具体价位——画出需求曲线）

问："基于我们刚才聊的，这个工具您愿意每月付 **¥___** 吗？" 从中间价位开始，根据回答上下调整。建议阶梯：

> ¥299 → ¥599 → ¥999 → ¥1,499 → ¥1,999 → ¥2,999 / 月

每听到一次"愿意"，就往上加；每听到一次"不愿意"，就问**为什么**、以及什么情况下才值这个价。这样可以在你完全不主动报价的前提下，直接验证 ¥2,000 这个锚点。

### 6c. 测试"收费模式"，而不只是数字

- 如果是一个固定月费、覆盖最多 **50 只**动物，超出部分每只再收一点点费用——这种结构您能接受吗？每多一只收多少您觉得合理？
- 您更愿意**按月付**还是**按年付**？（年付往往意味着更强的承诺。）
- 您会不会更愿意**按卖出一只动物**来付费，而不是订阅？（测试另一种模式。）
- 这类采购谁来拍板——是您一个人，还是有合伙人/家人一起决定？

## 第 7 节 — 承诺与推进（真正的信号）（3 分钟）

> *空口无凭。这些问题能区分"想法不错"和"赶紧收钱"。*

- 如果这个产品今天就有，并且完全做到我们说的这些，您这个月就会开始用吗？有什么会让您犹豫？
- 您愿意以早鸟价加入一个**付费内测**吗？*（如果他在任何价位都犹豫，那之前的热情多半只是客气。）*
- 等有了早期版本可以试用时，我能再联系您吗？
- 还有哪些其他繁育者我应该聊聊？方便帮我介绍一下吗？

## 第 8 节 — 收尾（1 分钟）

- 关于管理动物健康或销售，还有什么我*没问到*、但其实应该问的吗？
- 道谢。确认后续跟进。把"帮忙转介绍"具体落实下来。

---

## 要重点留意的信号


| 🟢 强信号                  | 🔴 弱信号 / 容易误导    |
| ----------------------- | ---------------- |
| 能讲出具体的、最近的损失，还带数字       | "总体上挺麻烦的"（含糊）    |
| 已经在用各种凑合办法（Excel、本子、微信） | "我都记脑子里，没问题"     |
| 主动提到"星期猫/星期狗"或纠纷        | 只有在你*推销之后*才兴奋    |
| 主动提出预付、内测或帮忙介绍他人        | "挺好！加油！" 但没有任何承诺 |
| 报价格区间时毫不犹豫              | 怎么都不肯说一个数字       |


## 单次访谈整理模板（访谈后立刻填写）

```
访谈人 / 日期：
繁育者画像：[品类] [种用动物数] [年销售数] [单价 ¥] [全职/副业] [销售渠道]
当前健康记录方式：[工具] [最大漏洞]
最糟糕的销售/交接经历：[退货？纠纷？星期猫？退款 ¥？]
估算的年度痛点（¥ + 小时/周）：
目前为哪些付费：[兽医 ¥ / 软件 ¥ / 投流 ¥ ...]
概念反馈（原话）："____"
必备功能 / 无所谓功能：
Van Westendorp：太便宜 ¥__ | 划算 ¥__ | 有点贵 ¥__ | 太贵 ¥__
Gabor-Granger 愿意付到：¥____/月
模式偏好：[固定+超额 / 按只] · [月付 / 年付] · 每多一只合理价 ¥__
承诺程度：[愿意内测并付费 / 有兴趣 / 仅客气]
转介绍：[姓名]
```

## 汇总分析（约 10 个访谈之后）

- **可接受价格区间：** 多个繁育者 Van Westendorp 曲线的重叠区域。
- **需求曲线：** 在每个 Gabor-Granger 价位上回答"愿意"的比例 → 找到收入最大化的价位。
- **分群差异：** 规模更大/犬舍 vs 猫舍/全职繁育者，是否聚集在更高的付费意愿？（可能为 Lite 与 Standard 分层提供依据。）
- **现实校验：** 真正给出*承诺*（内测/转介绍）的比例，而不只是报了个价。

## 该做 / 不该做

- ✅ 让他们先说出第一个数字。 ❌ 永远不要用你的价格先锚定。
- ✅ 问最近一次真实发生的事。 ❌ 只问"你会不会……"这种假设性问题。
- ✅ 每次都追问"为什么是这个数？" ❌ 拿到数字却不问原因。
- ✅ 把转介绍/内测当作真相。 ❌ 把夸奖当作验证。
- ✅ 猫舍犬舍、大小规模都访谈。 ❌ 凭 2–3 次聊天就以偏概全。
